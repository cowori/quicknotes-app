# QuickNotes

QuickNotes is a simple note-taking web application built with HTML, CSS, and JavaScript. It allows users to create categorized notes, search their notes, delete individual notes, clear all notes, and keep their data after refreshing the browser.

## Features

- Add notes with Personal, Work, or Study categories
- Validate empty notes and notes longer than 200 characters
- Display each note's category and creation date
- Delete individual notes
- Search notes without case sensitivity
- Save and restore notes using localStorage
- Display correct note counts for zero, one, or multiple notes
- Clear all notes after confirmation
- Responsive layout for desktop and mobile screens
- Different visual styling for each note category

## How to run the project locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension.
4. Alternatively, open `index.html` directly in a web browser.
5. Add, search, and delete notes in the application.
